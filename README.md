# C# Programming Practice & Assessments

A structured collection of C# console applications, assignments, and practical exam solutions built during enterprise software training.

## Repository Structure

- **`Assignment/`** — Core C# exercises covering object-oriented programming, collections, generics, and file/exception handling.
- **`Exam/`** — Timed practical assessment implementations demonstrating end-to-end business logic and data manipulation.
- **`Study Material/`** — Reference code snippets and syntax notes for quick revision.

## Tech Stack

- **Language:** C# (.NET Framework / .NET)
- **IDE:** Visual Studio

## How to Run

1. Clone or download the repository.
2. Open the `.sln` file inside the respective folder in **Visual Studio**.
3. Press `Ctrl + F5` to build and run the project.
